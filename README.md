# PeaBox IDE v0.8 — Polished Interface

## New in v0.8
- Complete native desktop menu bar: File, Edit, Selection, View, Go, Run, Source Control, Terminal and Help
- Redesigned dark interface with improved typography, spacing, colors, tabs, panels and status bar
- Branded PeaBox title area
- Icon-style activity bar with tooltips and active states
- Breadcrumb path above the editor
- Resizable sidebar and bottom panel
- Native editor context menu
- Native file context menu with copy path and reveal-in-Explorer actions
- Clear keyboard-shortcut labels in desktop menus
- Improved About window and keyboard-shortcut help

## Existing developer features
Monaco editor, Pyright LSP, semantic Python completion, hover, diagnostics, definition/reference navigation, rename, code actions, outline, project checks, integrated terminal, Git features, project search, recent projects and portable packaging.

## Install
Extract to a new folder and double-click `setup-peabox-ide.bat`. Later use `run-peabox-ide.bat`.

## Portable package
Double-click `build-portable-exe.bat`. Outputs are written to `dist`. Packaged users do not need Node/npm.
